# Crypto-Protocol

Python, C를 이용한 **암호화·복호화 및 암호학 관련 프로그래밍 연습 프로젝트 모음**입니다.

여러 프로그래밍 언어로 암호 관련 코드를 작성하며 암호 연산의 기본 원리와 구현 과정을 학습하고, 응용 암호학 및 정보보안 분야의 기초 역량을 쌓는 것을 목표로 합니다.

## 프로젝트 목표

- 여러 프로그래밍 언어를 활용한 암호 연산 구현 연습
- 암호화 및 복호화 과정에 대한 이해
- 암호학 개념을 실행 가능한 프로그램으로 구현하는 경험 축적
- 응용 암호학 및 정보보안 분야의 학습 기반 마련

## 사용 언어

- Python
- C

## 프로젝트 구조

```text
Crypto-Protocol/
```

각 디렉터리는 프로그래밍 언어를 기준으로 구분되어 있으며, 관련 연습 코드와 실험 코드를 포함합니다.


운영체제에 맞는 명령으로 생성된 실행 파일을 실행합니다.

## 프로젝트 범위

이 저장소는 암호학 관련 프로그래밍 학습과 실험을 위한 공간입니다.

- 각 프로그램의 구체적인 기능은 개별 소스 코드에 따라 다릅니다.
- 모든 구현이 상용 환경에서 사용할 수 있도록 검증된 것은 아닙니다.
- 실제 보안 시스템에 적용하려면 알고리즘의 정확성, 입력값 처리, 키 관리 및 기타 보안 요구사항을 검토해야 합니다.
- 충분한 검토와 테스트 없이 실험용 코드를 민감한 데이터 보호에 사용해서는 안 됩니다.
